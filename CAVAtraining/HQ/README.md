# CAVA Training Series

**From Climate Information to Climate Impact Analysis**

This training introduces the CAVA ecosystem and shows how to move from accessing climate information to reproducible analysis and agricultural impact modelling. The programme progresses from accessible platform workflows to more technical work with climate data and crop models.

## Training structure

- **Module 1 — Introduction to the CAVA ecosystem:** climate information, models, uncertainty, and the role of CAVA.
- **Module 2 — Using the CAVA Platform:** finding, visualizing, and interpreting climate information for a selected area.
- **Module 3 — Climate data workflows:** environment setup and practical notebooks using CAVAanalytics and cavapy.
- **Module 4 — From climate data to crop modelling:** preparing CAVA outputs for agricultural analysis with pyAEZ.

Modules 1 and 2 are suitable for a broad audience. Modules 3 and 4 are more technical and include hands-on exercises.

Each module folder contains its presentation and any supporting notebooks or instructions.
