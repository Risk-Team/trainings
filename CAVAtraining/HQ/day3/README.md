# Module 3: CAVAanalytics and cavapy

Module 3 covers the software setup and practical climate-data workflows used in CAVA.

## Files

- `CAVA_Module_3.pptx` — presentation covering the roles of CAVAanalytics and cavapy, shared climate datasets and OPeNDAP access, installation instructions, and the practical-session agenda.
- `CAVAanalytics_Training.ipynb` — R notebook for the hands-on CAVAanalytics exercises.
- The cavapy notebook will be provided separately by Sam.

## Data

The CAVAanalytics notebook reads `data/kenya_tasmax_1991_2000_2041_2050.rds`. Download that file from this Dropbox folder and place it in `data/`:

<https://www.dropbox.com/scl/fo/q2r1t0wi7zejpxgpknb8a/ABf22Xf0KjAQmicWTehsTCs?rlkey=nma7py3jme8kfk82koiigj8qi&dl=0>

If the file is missing, the notebook loads the data remotely instead. That step takes about 10 minutes and needs internet access.
